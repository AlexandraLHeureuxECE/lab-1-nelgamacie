# 🎮 Web-Based Tic-Tac-Toe Game

This project is a browser-based Tic-Tac-Toe game developed as part of a university lab focused on LLM-assisted software development. The game allows two players to play on the same device with turn-taking, win/draw detection, and interactive UI feedback.

## Running the Project Locally

No installation or build tools are required.

1. Download or clone the repository.
2. Navigate to the project folder.
3. Open **`index.html`** in any modern web browser (Chrome, Edge, Firefox, Safari).

The game will load and run directly in the browser.

## LLM Tools Used

This project was developed using LLM-assisted coding tools:

* **Cursor** — Primary tool used for code generation, refinement, UI improvements, and debugging.

## Features

* Interactive 3×3 Tic-Tac-Toe grid
* Turn-based gameplay (X starts)
* Automatic win and draw detection
* Visual highlight of winning combination
* Fixed-size responsive grid layout
* Restart game without page refresh
